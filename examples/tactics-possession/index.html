What is being remixed?

Real 0 A.D. squad command code generates movement, attack and stance orders. An adapter translates those orders into this original browser battle. This is not the full 0 A.D. engine.

The browser owns movement, combat and saves. Both views use the same soldiers and health. Original scenery; no proprietary game assets.
