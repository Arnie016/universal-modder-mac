# Play Worlds Garden

**Dooley Doo · public playtest · version 0.4.4**

Server address: **54.169.34.180** (port **25565**).

## Join

1. Sign in to your licensed **Minecraft Java Edition** account.
2. Install **Minecraft 26.3**, **Fabric Loader 0.19.5** and **Java 25 or newer**, using the [official Minecraft launcher](https://www.minecraft.net/download) and [Fabric installer](https://fabricmc.net/use/installer/). Keep this in a separate installation/game folder.
3. Extract this client pack. Copy both files from `mods/` into that installation's `mods/` folder.
4. Start the Fabric installation. Select **Multiplayer → Add Server**, name it **Worlds Garden**, and enter **54.169.34.180**.
5. Join the garden. Select hotbar slot **9** and right-click the compass to choose a game. Slot **8** holds the field guide. Ordinary players need no operator access.

On the creator's Mac, the separate **Worlds Garden 0.4.4** launcher installation is already prepared.

## Choose a game

- **Sling Siege:** launch birds, trigger their powers and clear the pigs. Rounds reset automatically.
- **Frostline GP:** set up your pod in the garage, race three laps, boost and chase your best time.
- **Bloom:** enter the fungal conservatory, burn the roots, retrieve the specimen and extract.

The compass also opens your achievements and the upgrade shop. XP and credits are saved per player.
